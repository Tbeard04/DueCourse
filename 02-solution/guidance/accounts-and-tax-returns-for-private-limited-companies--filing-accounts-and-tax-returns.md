You [file your accounts with Companies House](/file-your-company-annual-accounts) and your Company Tax Return with HM Revenue and Customs (HMRC).

You’ll need to use commercial software to file your Company Tax Return with HMRC. There’s a list of [commercial software suppliers you can use to file your Company Tax Return](/government/publications/corporation-tax-commercial-software-suppliers).

You can [use the paper form (CT600)](/government/publications/corporation-tax-company-tax-return-ct600-2015-version-3) to file your tax return with HMRC if either:

  * you cannot file online because you have a [reasonable excuse](/tax-appeals/reasonable-excuses)
  * you want to file in Welsh



## Filing your accounts and Company Tax Return at the same time

You may be able to file them together if you have a private limited company that [does not need an auditor](/audit-exemptions-for-private-limited-companies).

You can look for [accounting software](/software-company-accounts) or a [commercial software provider](/government/publications/corporation-tax-commercial-software-suppliers) that lets you file both at the same time.

## Corrections and amendments

Check what you must do to correct or amend:

  * [your accounts](/annual-accounts/corrections-and-amendments)
  * [your tax return](/company-tax-returns/making-changes)



## Using accountants or tax advisers to file for you

You can:

  * give your accountant or tax adviser your Companies House authentication code so they can file your accounts
  * [appoint an agent](/appoint-tax-agent) to file your Company Tax Return
